Once the contract is deployed, the mint page will show its address. Before minting, you MUST call these read-only functions and report the exact results:
1. mintOpen() — if false, STOP.
2. totalMinted() — current count and remaining supply.
3. currentPrice() — exact price per NFT right now.
4. mintedPerWallet(MY_WALLET) — if already 11, STOP.

Then ask me to confirm the quantity (1–11, never more than 11 minus what I already minted). Only after confirmation, call mint(QUANTITY) and send exactly currentPrice x QUANTITY in BNB. Do NOT approve any token spending — this mint is paid in native BNB only. After the transaction, report the transaction hash and new token IDs.

04 — FAQ

What is PTERODAKTIL?

A 1,600-piece NFT collection of fossil specimens: 16 unique specimens × 100 editions each. Each token shows a golden skeleton preserved on a white marble slab with a glowing blue runic border.

How much does it cost?

0.0005 BNB per NFT, flat price for all tokens.

How many can I mint?

Max 11 per wallet, cumulative across all mints.

When does mint open?

Not yet — this page is a preview. Mint opens after the contract is deployed.

What do I receive?

A BEP-721 token on BNB Chain with the specimen artwork and metadata. Token IDs are drawn randomly (1–1,600); the specimen of each token follows its ID range (100 editions per specimen).

Are the cards random?

Yes. Each mint draws random token IDs from the remaining pool, so the 11 IDs in one transaction are always different from each other. They usually span several specimens (about 8–9 different kinds per 11-mint on average), but 11 different specimens are not guaranteed. The randomness is on-chain pseudo-random, not Chainlink VRF.

Is this affiliated with Binance?

No. PTERODAKTIL is an independent project on BNB Chain, not a Binance collaboration.
